# 한 칸의 발견

**주소나 QR코드로 접속하는 실시간 형성평가 말판놀이 웹앱**입니다. 특정 교과에 종속되지 않도록 교사가 문제, 팀, 힌트, 특별카드를 입력할 수 있습니다.

## 실행하기

Python 3.10 이상이 필요합니다.

- **Windows**: 압축을 푼 뒤 `start_windows.bat`를 더블클릭합니다. 처음 실행할 때 필요한 패키지를 설치합니다.
- **macOS / Linux**: 터미널에서 `bash start_mac_linux.sh`를 실행합니다.
- **수동 실행**: 다음 두 명령을 실행합니다.

  ```sh
  python -m pip install -r requirements.txt
  python -m uvicorn main:app --host 0.0.0.0 --port 8000
  ```

같은 컴퓨터의 브라우저에서 `http://localhost:8000`을 엽니다. 학생이 같은 와이파이의 다른 기기로 접속하려면 **교사 컴퓨터의 내부 IP 주소**(예: `http://192.168.0.15:8000`)로 접속해야 합니다. 컴퓨터의 방화벽에서 해당 포트에 대한 접근을 허용해야 할 수 있습니다. `localhost`에서 게임방을 만들면 QR코드에도 로컬 주소가 들어가므로, 휴대전화로 QR을 찍어 접속하려면 **먼저 학생이 접속할 수 있는 주소로 페이지를 연 다음 게임방을 생성**하세요.

학교 외부에서 URL·QR로 접속시키려면 아래와 같이 **웹 서버에 배포**해야 합니다. 앱 파일만으로 공개 인터넷 주소가 자동 발급되는 것은 아닙니다.

## 게임 만드는 순서

1. **새 게임 만들기** → 문제 5~48개, 참가 팀 2~8팀, 오답 추가 입력 기회 0~3회 설정
2. 팀별 이름과 문제, 정답, 힌트 입력. 단답형과 4지선다형 지원. 단답형의 여러 정답은 `정답1|정답2`처럼 구분
3. 특별 퀴즈 카드에 **도착 칸 번호**, 문제, 교사용 참고 정답을 입력. 나중에 교사가 맞음/틀림 버튼으로 판정
4. 다섯 효과음을 개별 켜고 끄거나 음량 설정
5. 게임방 생성 후 교사용 관리실의 **학생용 주소 또는 QR코드** 공유
6. 교사는 팀별 **6자리 참가 코드**를 각 팀에 전달하고 **게임 시작** 클릭

교사 화면에는 비밀 관리 링크·참가 코드가 표시됩니다. **교사 링크를 학생에게 보내지 마세요.** 학생에게는 교사 화면의 **학생용 입장 링크**만 보내세요. 전광판 링크는 읽기 전용으로 교사용 비밀 정보와 정답이 빠져 있습니다. 교사가 화면 공유 기능으로 관리 화면을 직접 보여주는 것도 가능합니다. 교사용 정답은 세부 정보 펼치기 전에는 숨겨집니다.

## 다른 반에 재사용하기 / 기록 초기화하기

교사용 관리실에는 서로 다른 두 버튼이 있습니다.

| 메뉴 | 교사 설정 | 진행 기록 | 학생 접속 주소·코드 | 기존 반에 미치는 영향 |
|---|---|---|---|---|
| **＋ 다른 반에 재사용** | 문제·정답·힌트·특별카드·팀 이름·효과음 설정 그대로 복사 | 새 반 기록 0부터 시작 | **새 게임방 코드, QR, 교사용 비밀 키, 팀별 참가 코드** 생성 | **기존 반의 기록과 방은 그대로 보존** |
| **↻ 현재 게임 초기화** | 그대로 유지 | 말 위치·힌트 사용 횟수·차례·주사위·현재 문제·문제 사용 순서·승자·이동 효과/활동 기록 **모두 초기화** | **같은 주소, 같은 참가 코드** 유지 | 기존 반의 게임 기록을 삭제하므로 **복원 불가** |

**다른 반 수업에 권장하는 방법:** 이전 반에서 사용한 교사용 화면의 **＋ 다른 반에 재사용**을 누르고, 새 화면의 학생용 QR과 각 팀의 **새 참가 코드**를 배포합니다. 이전 반 학생이 새 게임방에 자동으로 참여하지 않으며, 두 반의 기록은 독립적입니다. 새 반은 교사의 **▶ 게임 시작**을 눌러 진행합니다. 반별 기록을 분리하지 않고 단지 같은 반에서 다시 할 때만 **현재 게임 초기화**를 사용하세요.

**기록 보존 주의:** 재사용하여 만든 새 방은 별개의 저장 데이터이므로, 서버를 계속 운영하는 동안 이전 반의 방도 남습니다. 다만 무료/임시 호스팅에서 서버 데이터가 사라지면 두 방 모두 복구되지 않을 수 있습니다. 기본 버전에는 기록 내보내기나 별도 백업 기능이 없습니다.

## 정확한 게임 규칙

| 상황 | 동작 |
|---|---|
| 주사위 | 1~6 눈의 주사위 2개를 굴릴 때마다 더하기(+), 빼기(−) 중 무작위 선택. 빼기는 **큰 눈과 작은 눈의 차**, 즉 절댓값. 0칸이면 이동 없이 일반 문제에 답함 |
| 일반 칸 | 말을 **임시 이동**한 뒤 문제를 풀고 정답이면 새 칸 확정, 최종 오답이면 이동 전 칸으로 복귀 |
| 오답 재입력 | 교사가 설정한 **추가** 기회만 허용 (0이면 총 1회, 1이면 총 2회) |
| 힌트 | 전체 게임에 걸쳐 팀당 최대 **5회**. 같은 문제에 두 번 사용할 수 없음. 힌트를 입력하지 않은 문제에는 버튼이 나타나지 않음 |
| 특별 퀴즈 칸 | 일반 문제 대신 교사가 별도 카드의 정답/오답 판정. 맞으면 해당 칸에 머무름, 틀리면 이동 전 칸으로 복귀 |
| ↩ 처음으로 | 출발점인 0칸으로 이동, 즉시 차례 종료 |
| ↔ 선두 교환 | 현재 팀보다 앞선 팀이 있으면 선두 팀과 위치 교환. 이미 선두라면 위치 유지. 즉시 차례 종료 |
| 🌀 포털 A, B | A에 도착하면 B로, B에 도착하면 A로 이동. 연속 포털 재발동은 하지 않음. 즉시 차례 종료 |
| 결승점 | 마지막 칸에 도착한 뒤 일반 문제를 맞히면 승리. 마지막 칸을 넘는 이동은 마지막 칸에서 멈춤 |
| 차례 제한 | **서버**가 현재 팀의 참가 코드를 확인. 다른 팀은 주사위·힌트·답안 제출 불가 |

**말판 칸 수**는 `기본 문제 수 + 8`칸입니다. 예를 들어 8개 문제면 0~15, 총 16칸입니다. 특별 이벤트 4칸(처음으로 1, 선두 교환 1, 포털 A/B 각 1)은 서로 겹치지 않게 자동 배치됩니다. 교사가 별도의 특별 퀴즈 칸을 추가할 수 있습니다. 일반 문제는 등록한 문제를 한 번씩 무작위로 사용한 뒤 재섞습니다.

## 효과음

음원 파일이나 외부 음원 서비스 없이 브라우저의 Web Audio API로 직접 소리를 합성합니다. 기본 설정은 다음과 같습니다.

- **말 이동**: 가볍게 올라가는 3음
- **특별 퀴즈**: 반짝이는 4음
- **포털**: 위아래로 휘어지는 공간 이동음
- **출발점 복귀**: 내려가는 저음
- **선두 위치 교환**: 교차하는 4음

기기별 브라우저의 자동재생 제한 때문에 게임 화면의 **♫ 소리 켜기** 버튼을 처음 한 번 눌러야 소리가 납니다. 교사는 게임 중에도 효과음 종류와 음량을 변경할 수 있습니다. 별도의 WAV/MP3 파일은 필요 없습니다.

## 실제 웹 주소로 배포하기 (예: Render)

1. 앱 폴더의 **소스 코드**를 본인 GitHub 저장소에 올립니다. 보안을 위해 `data/` 폴더를 올리지 마세요.
2. Render에서 새 **Blueprint**를 만들고 저장소를 연결합니다. 동봉된 `render.yaml`이 파이썬 웹 서비스 실행 방법을 정의합니다.
3. 배포 후 만들어진 `https://...onrender.com` 주소를 열고 새 게임을 생성합니다.
4. 교사 화면에서 해당 주소를 이용한 **학생용 QR코드**가 자동 생성됩니다.

**데이터 보존 주의:** 기본 저장소는 로컬 SQLite 파일(`data/rooms.sqlite3`)입니다. 임시 파일 시스템을 쓰는 무료 호스팅에서는 서비스 재배포·재시작 때 게임방 데이터가 삭제될 수 있습니다. 지속적으로 사용하려면 영구 디스크가 있는 호스팅을 사용하거나 데이터베이스를 영구 서비스로 이전해야 합니다. Render의 무료 웹 서비스는 유휴 시간에 멈췄다가 다시 켜질 수 있으므로 수업 시작 전에 접속 상태를 확인하세요. 다중 서버 인스턴스 환경은 이 버전에서 지원하지 않습니다.

## 관리, 개인정보, 보안

- 학생의 **이름·계정·이메일은 필요하지 않습니다.** 팀 이름과 선택적으로 입력한 문제·답안만 서버에 저장합니다.
- 팀 참가 코드와 교사용 비밀 링크를 공유 대상에 맞게 관리하세요.
- 정답은 학생 API로 보내지지 않습니다. **사용 전 힌트도 학생 API에서 숨겨집니다.** 팀 차례는 서버 측에서 검사합니다.
- 교사가 브라우저의 히스토리, 링크 복사 기능 등으로 실수로 비밀 교사용 주소를 공유하지 않도록 주의하세요.
- 공개 서비스 운영·학교 정식 도입 전에는 인증 보안, 백업·접근 제어·로그 정책을 별도로 검토하는 것이 좋습니다. 이 버전은 수업용 시범 운영을 위한 단일 서버입니다.

## 구성

```
main.py                Python FastAPI 웹 서버 · 실시간 전송 · 데이터 저장 · 규칙
static/index.html      화면 구조
static/style.css       반응형 화면 디자인
static/app.js          화면 동작 · 다섯 효과음 · QR 참여 · 실시간 갱신
requirements.txt       설치 패키지
render.yaml            Render Blueprint 설정
start_windows.bat      Windows 실행 스크립트
start_mac_linux.sh     macOS/Linux 실행 스크립트
tests/test_app.py      접근 권한, 힌트/정답 숨김, 판정, QR 테스트
```

테스트: `python -m unittest discover -s tests -v` (개발/검증용 `httpx`가 필요합니다).


## Windows 설치 문제 해결 (v3)

`start_windows.bat`은 Python 3.12 또는 3.13을 선택해 앱 전용 가상환경에서 실행합니다. Python 3.15만 설치되어 있으면 PyYAML 등의 의존성 빌드 과정에서 Microsoft C++ Build Tools 오류가 발생할 수 있습니다. Python 3.12.10 Windows 64-bit 설치 프로그램을 https://www.python.org/downloads/release/python-31210/ 에서 받아 설치하세요. Python 3.15는 삭제할 필요가 없습니다. **반드시 ZIP을 먼저 완전히 압축 해제**한 뒤 `start_windows.bat`를 더블클릭하세요. `http://127.0.0.1:8000`은 서버를 실행 중인 같은 컴퓨터에서만 열립니다. 학교 밖에서 QR로 접속하려면 별도의 배포가 필요합니다.
